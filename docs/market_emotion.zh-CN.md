# 市场情绪观察模块

本模块只采集和展示事实，不进入正式评分、veto、仓位或交易调用链。

## 入口与依赖

```powershell
.\.runtime\market_sentiment_env\Scripts\python.exe scripts\collect_market_emotion.py
```

zzshare 0.4.12 安装在 `.runtime/market_sentiment_env`，发布 wheel SHA256 为
`3a276653d53852e85a18d93d65e31b0768d256797239796b025c318ff57a02c0`。
该环境通过明确的 `.pth` 复用主项目现有 AKShare/pandas 等依赖，不修改主环境和 `uv.lock`。
不安装 MCP extra，不启动第三方服务器。发布包与审核过的 SDK 核心源码一致。

Hermes 入口为 `E:\hermes\scripts\market_emotion_collect.py`，使用独立解释器调用上述命令。
`--dry-run` 仅显示调用路径。纯脚本任务，输出存本地，不新增通知数量。
原生启动器使用 `locale.getencoding()` 与现有调度器的文本捕获编码一致；内部采集器和落盘文件使用 UTF-8。

## 数据与口径

- 市场宽度：通过 Router GET 读取完整证券清单并分页，再用腾讯批量行情；使用每股实际行情时间，金额由万元转元。至少 98% 当前日期及有效时间的覆盖率才能输出市场宽度。
- 涨跌停/炸板：现有 AKShare/东财接口。校验原始 `rc/qdate/tc/pool`，核对完整性和证券去重。只有日期正确且原始池与总数均为 0 的空表才作为真实 0；失败和缺失为 null。
- 东财股池源代码声明不含 ST、科创板和未中断连续一字涨停新股。这个统计不是全 A 股涨跌停总数。
- 晋级率：使用当前交易日明确的 YesterdayZTPool，读取“昨日连板数”作为前一交易日固定队列。普通历史 TopicZTPool 的 qdate 实测可与请求日期不同，不用于构造该队列。原始响应和首次可用时间均保留，不假装历史当时已采集。
- 题材：东财概念涨幅与同源资金流；对当前涨幅前三概念采集成员、计算池内涨停归属。当前成员仅供本次观察，不反填过去；板块存在交叉归属，题材涨停数不能求和当市场总数。
- 高度锚：保留并列最高标，跟踪昨天最高标的当前封板状态；盘中未封板不等于最终断板或龙头死亡。
- 席位：龙虎榜已发布时获取名单前三个去重股票的买卖两侧，使用原始命名字段和营业部 ID，按榜单类型去重；冲突保留缺失。“机构专用”及 ID=0 不是唯一席位，保留不同经济记录及同侧重复数量，只对两侧完全相同的记录去重。不根据席位名称认定具体交易人。此层明确为样本，未宣称全市场覆盖。
- zzshare：只作供应商衍生信息和补充；空字典中的业务集合、空表和 None 分开处理。综合情绪日期必须匹配目标日期，不参与正式评分。匿名请求一次、有限超时，不使用主应用凭证。

## 状态与输出

`reports/market_emotion/` 保存每次原始响应、hash、追加式 SQLite 快照、`latest.json`、`latest.md` 和有效收盘日进度。

`CORE_COMPLETE` 只表示市场、前三题材、锚股所需核心字段就绪；不是全功能验收。
`layer_status` 分别报告各层状态。周期仍为 UNKNOWN，席位可能未披露/不可用。
V3 元数据里的 component coverage 包含本模块未采集的强势股池，其值不能替代 `quote_coverage_ratio`。

盘中为 INTRADAY，早盘后为 PRELIMINARY。上海时间 16:00 后且核心市场数据通过校验才可 FINAL。
实际盘后成功仍需定时运行证据，盘中实测不能替代。

SQLite 按快照 ID 追加，同一快照重复保存不新增；修订保留历史。
单写入锁避免并发。每个来源在可终止的子进程中运行，单进程 35 秒超时，启动器总时限 300 秒。
日历不可用时整次跳过写入；源失败时输出 PARTIAL 和缺失原因。

`daily_sim_snapshot.py` 仅在输出头部读取此前可用的观察摘要；读取失败不阻断原报告。
摘要超 10 分钟标为“上一观察快照”，拒绝读取决策时点之后才可用的记录。

## 调度与验收

建议采集时点为上海时间 11:25、14:25、15:20、16:10、18:30。
部署时按 Hermes 调度器实际时区换算，并核对持久化 `next_run_at`，不得直接沿用本机表盘。
新任务使用现有 Hermes 调度器；部署记录保存实际 job ID、时区和下次时间。

20/30/60 个有效 FINAL 交易日只表示到达数据质量/稳定性/研究检查点，不能自动视为盈利有效。
周期规则、交易收益影响、样本外结果仍需单独验证。现有质量闸门保持原有语义。

回退时停用登记的新任务并移除日报的摘要读取块即可。保留已采集原始数据与历史，不回滚用户其他改动。
