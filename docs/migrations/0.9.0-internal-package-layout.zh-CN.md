# Router 0.9.0 阶段 6：内部目录整理

> 完成日期：2026-07-27

## 范围

阶段 6 只迁移 Python 包路径和整理命名，没有修改业务规则、HTTP API、Pydantic 响应结构或
DuckDB Schema。所有模块均采用移动方式，不保留旧根模块的业务逻辑副本。

## 新目录

```text
trading/
├─ research/
│  ├─ technical/
```

## 不变量

- Router 版本仍为 `0.9.0`。
- OpenAPI path、method、deprecated 标记和响应 Schema 不变。
- DuckDB 表、列、约束和账本聚合逻辑不变。
- DecisionPacket 哈希和不可变规则不变。
- Paper Trading 与人工成交继续完全隔离。
- Finance Data MCP 继续只读。
- 不存在 broker、live execution、GUI 自动填单或外部交易客户端控制能力。
