# 实盘准备安全门槛

`aiquant-lite` 当前是投研和模拟分析系统。Provider 连通性测试通过，不代表系统已经可以
安全控制真实资金账户。

启用实盘订单前，必须完整实现、测试并由独立人员复核以下门槛：

1. **职责分离**：研究、信号审批、订单构造和券商执行必须是独立组件，并分别使用最小权限凭据。
2. **模拟盘磨合**：完整策略和运维链路至少连续运行 30 个交易日，记录滑点、拒单、延迟、
   中断和对账差异。
3. **确定性订单校验**：强制执行证券白名单、交易时段、手数、价格笼子、单笔金额、最大仓位、
   集中度、换手率和单日亏损限制。
4. **人工审批**：新策略、高风险信号、异常订单规模和任何规则豁免都必须由已认证人员审批。
   大模型复核不等同于人工审批。
5. **幂等与重放安全**：每个订单意图必须有稳定的客户端订单号，任何重试都不能产生重复订单。
6. **紧急停止**：提供经过测试、完全不依赖大模型的停止开关，可阻止新订单并撤销未成交订单。
7. **券商对账**：持续核对本地意图、券商确认、成交、现金、持仓、费用和公司行为；未知差异
   必须立即停止交易。
8. **故障隔离**：明确定义数据陈旧、来源冲突、Provider 故障、网络分区、时钟偏差、数据库
   故障和券商部分响应时的处理方式，默认关闭而不是冒险继续。
9. **不可变审计链**：保存决策输入、证据、策略版本、审批、订单请求、券商响应、成交和人工操作，
   并确保时间同步。
10. **密钥隔离**：券商交易凭据不得进入模型 Prompt、通用 Agent 环境、源码、日志或 Hermes
    消息网关运行环境。
11. **运维控制**：上线前必须演练告警、值班责任、事故预案、备份恢复、密钥轮换、依赖锁定和回滚。
12. **法律与券商审查**：确认账户权限、交易所规则、数据许可、自动化条款、税务、报告义务和部署地法规。

实盘启用应要求一份带版本号的准备报告，并由系统负责人和独立复核人共同签署。在此之前，
所有下单适配器必须默认关闭或仅运行模拟模式。
