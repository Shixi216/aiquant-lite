# Hermes 研究工作流

**Agent 的价值在于把已验证的工具接进研究流程，并把依据带回给使用者。** 本页从项目经验提炼工作流，用公开接口承接；私人提示词和第三方技能目录不在发布范围。

| 工作流 | 先读取什么 | 输出保留什么 | 后续边界 |
|---|---|---|---|
| **数据与服务诊断** | 组件状态、业务日期、覆盖率、数据新鲜度 | 来源、失败类型、缺失项、可复核接口 | 空结果、源失败和去重状态异常分别处理 |
| **单标的证据研究** | 证券身份、行情、财务、公告与来源核验 | 公司事实、板块背景、模型推断分别解释 | 不用板块新闻代替公司事实；研究候选不自动进入决策 |
| **市场观察日报** | 已落库市场快照、观察层状态、截止时间 | 事实、变化、未确认项与时点 | 观察记录与模拟成交分别留存 |
| **模型对照实验** | 协议、独立标注、数据版本与基准 | 有效样本、成本、失败案例和不确定项 | 不用模型自己的答案充当独立 ground truth |

## 公共工具链

公开 Finance MCP 契约把自然语言筛选、结构化 `ScannerQueryPlan`、本地扫描、有限候选研究与单标的决策评估串起来。筛选解释先展示，研究范围有上限，决策评估需要 `CONFIRM_DECISION:<symbol>`。Scanner 输出不会自行进入 DECISION。

该集成流程的决策工具不创建订单，也不创建 DecisionPacket；其他系统流程的版本化决策包能力需按各自契约解释。手工成交录入另有预览与明确确认机制，研究 Agent 和定时任务不能代替使用者确认。

流程优先复用已有工具，并核对当前数据状态。渠道配置、个人观察池、完整记忆和授权材料不进入公开工作流。外部模型与数据是否可用，仍取决于本地配置及服务状态。
