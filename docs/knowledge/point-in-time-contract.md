# PIT、时间与冻结实验协议

**研究能否成立，首先取决于信息在当时是否可得。** 本页整理项目已有时点约束和冻结研究经验；它是审核协议，不代表每项本地归档都已重新通过完整 PIT 审计。

## 四种时间，分别解释

| 字段语义 | 判断用途 |
|---|---|
| 事件发生时间 | 描述事件所属时点，不能单独证明市场当时已知 |
| 来源可得时间 | 判断该条数据能否进入该次研究 |
| 决策截止时间 | 固定研究者当时可看到的信息边界 |
| 抓取 / 报告生成时间 | 说明何时入库、何时输出；不能替代历史可得时间 |

输入要求来源可得时间不晚于截止时间。历史回填、修订报表或当前概念成员，必须按实际语义处理；当前成员关系标为 `CURRENT_MEMBERSHIP_ONLY`，不冒充历史成员证据。缺少当时的主题名称时保留为空。

A 股业务时间显式采用 `Asia/Shanghai`。部署机器时区、无时区 datetime 和 SQL 会话时区不能隐式决定交易日。公开回归已覆盖不同会话时区下的截止日与事实日判断。

## 研究输入与事后评价分开

在线特征、研究状态与未来收益标签分别保存。1 / 3 / 5 / 20 日的未来结果可供事后评价，不能反向修改当时的状态、名称、成员关系、置信度或正式权重。主题的事后解释也不能变成事前标签。

每轮研究应固定代码版本、数据版本、股票池、特征与标签定义、成本、训练与验证窗口。Walk-Forward 研究还需写明 purge、embargo 和样本是否曾被观察；研究者看过的年份不能重新命名为 pristine holdout。

失败后建立新版本并保留原报告。哈希可用于识别文件是否变化，DecisionPacket 可校验冻结内容的完整性；哈希一致本身不能证明数据 PIT 正确或方法盈利。
