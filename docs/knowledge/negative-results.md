# 失败实验与无效基准案例

**保留被否定的路线，让下一轮研究少重复一次错误。** 以下为已有研究材料的归纳，本次未重新计算收益或显著性。

| 观察到的问题 | 如何识别 | 沉淀为规则 |
|---|---|---|
| 截面信息为正，净超额仍不足 | Multi-Factor V1 同时查看排序相关、毛超额、换手与成本后结果 | 因子筛选与组合可交易性分开验收 |
| 聚合指标较强，年度表现不稳定 | Strategy Lab 的动态与 Ridge 路线在旧报告的 2026 分段转弱或转负 | 聚合优胜不能绕过年度与折间检验，复杂度需要额外理由 |
| Delta 为正，绝对效果仍弱 | S3C1 同时核对负 Baseline、绝对 RankIC、风格残差与年度稳定性 | 基准有效性和绝对效果一起报告 |
| 标签曲线看起来像净值 | 重叠 forward-return labels 并非资金守恒下的持仓轨迹 | 组合收益需使用明确定义的入场、退出、成本与持仓协议 |
| 模型自评形成“真值” | 输出与评测标签来自同一模型链路 | 使用独立、带来源的标注；人工不确定项不进入正式对照 |
| 单个案例被推广为通则 | 用短期个股涨跌评价整个方法 | 以多期、多样本、成本和样本外证据检验假设 |

这些案例构成研究资产，不能据此推断所有路线均无效，也不能把旧报告中的正结果升级成实盘承诺。新版本保留基准、拒绝理由和未解决事项，再增加新的验证数据。
