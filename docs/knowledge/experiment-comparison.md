## 比较前固定六项

1. **样本**：股票池、有效日期、财务覆盖、缺失处理是否一致。
2. **时点**：信号截止、数据可得、训练信息和历史成员是否符合 PIT。
3. **交易协议**：次开盘或次收盘入场、持有期、是否重叠、成交限制。
4. **成本**：佣金、税、滑点、换手和成本计费单位。
5. **验证**：训练 / 验证窗口、purge、embargo、已观察样本和年度稳定性。
6. **基准**：基准本身是否可执行、有效，是否只是一个负效果参照。

只有协议一致，收益、Sharpe、回撤和增量指标才适合并列比较。更复杂的模型需说明其增量是否稳定，失败候选与简单基准一起保留。
