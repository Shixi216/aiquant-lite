# 记忆与对话知识治理

**把长期对话变成带证据、带日期、可更新的研究资产。** 本次从本地项目相关会话、长期记忆及排障材料中归纳 8 个公开主题，保留研究方法与通用教训。

按项目目录或明确项目标记检索，共匹配 161 个 Hermes 项目相关会话。这是素材范围，不是 161 条已验证结论；关键词主题可能重叠。完整对话、私人记忆文件、工具转储和推理内容不公开。

## 一条知识的最小结构

| 字段 | 写入要求 |
|---|---|
| 主题与适用范围 | 说明用于哪个模块、研究路线和数据口径 |
| 证据与形成日期 | 能定位源码、落库状态、报告版本或独立事实 |
| 验证状态 | 区分已核查、历史报告、推断和未解决事项 |
| 当前有效性 | 数据源、配置、采集入口与结果引用前重新核对 |
| 冲突与替代关系 | 显式列出矛盾，由使用者确定正式版本 |

建议的记录结构示例：

```yaml
topic: historical_membership
scope: historical_replay
rule: current membership is insufficient historical evidence
evidence: trading/research/sentiment/v3/sector_stock.py
verification: public_code_review
review_date: 2026-10-19
conflicts: []
```

对话中的结论不会自动变成当前代码事实。较新的文字也不能直接覆盖正式决策契约、风险约束或已经冻结的实验；先列冲突，核对证据，再形成有明确批准者和版本的新规则。

## 知识如何进入下一轮工作

先提取候选知识，删除私人身份、渠道与账户信息，再核对源码或已落库事实，检查重复和冲突，最后写成可复用文档。副本按内容识别，不把备份数、技能入口数、工具消息数当作独立知识规模。

本次发布的是原创整理的 8 个主题，未整体复制个人提示词或第三方技能。研究案例可以解释如何建立假设，单次涨跌不能自动升级为通用规则。
