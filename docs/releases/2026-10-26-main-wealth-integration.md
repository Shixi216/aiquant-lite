## 正式评分：以实际代码和接口为准

现行主路径是四维横截面 `cross_section_4d`：技术 **30%**、基本面 **30%**、结构化情绪 **25%**、两融资金 **15%**。输入为居中的横截面 rank；缺失维度按可用项权重重新归一，不能理解为每只股票都具备四个完整维度。股票正式分、五维解释材料与财富策略权重分别解释。

| 核查位置 | 代码中的实际行为 |
|---|---|
| [横截面计算](../../trading/research/orchestration/cross_section.py) | `FACTOR_WEIGHTS` 为 30/30/25/15；`weighted_composite` 对可用输入归一 |
| [正式分解析器](../../trading/decision_support/formal_score_resolver.py) | 优先读四维截面；有 cutoff 时仅读不晚于该时点的历史记录 |
| [canonical 决策输入](../../trading/decision_support/canonical_input.py) | 60/40 只作兼容来源标记，降级时正式分归零、等待 |
| [proposal 编排](../../trading/decision_support/orchestrator/service.py) | `legacy_60_40_fallback` 强制 HOLD，不据此新增仓位 |
| [动作阈值](../../trading/decision_support/thresholds.py) | 优先读取截面 P75/P90 阈值；数据、持仓和硬 VETO 另行约束动作 |

因此，旧功能分支介绍中的“正式权重固定 60/40”“情绪和资金正式权重为 0”不适用于当前系统，已从中英文主页移除。兼容代码仍存在，不声称它已经从源码删除。AI 新闻解释与四维结构化情绪 rank 也不是同一种输入。

- P75 / 建仓参考阈值：**0.23664462480606085**；P90 / 强档参考阈值：**0.42313743061987596**。
- 三条样本按可用因子独立重算，与接口误差均为 **0**：`0.9088616714697406`、`0.888330210592256`、`0.8742771486211889`。
- 其中一条只有技术 rank，其余两条没有两融 rank；这正是可用权重归一的实际样例。这里只核对公式与读取结果，不把这些样本当作投资推荐或数据质量认证。

干净副本的完整回归还发现一处发布遗漏：`test_root_cause_fixes.py` 已进入功能分支，但对应实现仍在共享工作区的未提交区。首次合并回归为 **1,892 passed / 21 failed / 4 skipped / 8 deselected**。本次逐项复现后补入 16 个必要实现路径，没有移除失败断言，也没有将这些用例标为跳过；单独复跑该模块已为 **29 passed / 0 failed**，并补入已有的扫描数据质量回归模块。

| 补齐的实现 | 修复行为 |
|---|---|
| 扫描条件与单位 | 完整数字不因正则回溯而丢失单位；手/股、千元/元和百分比只转换一次 |
| 日历与快照 | 请求目标日期不作为数据已完成的证明；日历不足、旧日期、日期缺失、覆盖不完整或多接口错日均不能放行 |
| 修订与 PIT | 修正日线追加为新修订，保留旧记录；读取端按交易日去重，只选截止前可见修订 |
| 批量持久化 | 证据引用一次批量解析，批次原子提交；重复抓取不重复入库，失败回滚 |
| 主库一致性查询 | 不对正在被 Router 使用的 DuckDB 文件额外开句柄计算 SHA；返回不可用原因 |
| 无因子证据 | 明确返回覆盖不足、空证据和不可用研究分数，不编造动作或决策包 |
| 小预算 DeepSeek 调用 | 保留调用方 token 上限；不足 4,096 时禁用推理前缀，不通过提高预算获得成功 |
| 日期输入与回测参数 | 合法日期随输入同步，避免仍使用上一个已提交日期；浏览器改为 2020-04-07 后得到 1,587 日、45.95% 收益，与显式 API 请求一致 |

与这些缺陷无关的本地实验、模型配置和运行文件没有批量纳入发布。股票四维权重和财富 v1/v2 字段保持既有契约。

依赖安全门禁发现两个依赖包存在公告，已在原有主版本范围内升级 Vite 和 follow-redirects，锁文件仅对应两包变化。依据：[Vite 7.3.7 修复公告](https://github.com/advisories/GHSA-587h-7wmj-h5pm)、[follow-redirects 1.16.1 修复公告](https://github.com/advisories/GHSA-q3jh-wrc6-jgq8)。
