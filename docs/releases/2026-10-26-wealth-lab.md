# Wealth Lab：让策略实验、风险证据与 AI 研究出现在同一个工作台

**2026-10-26 · AIQUANT-LITE 本地研究工作台更新**

保留原有 A 股扫描、研究与决策支持流程，新增独立的多资产 Wealth Lab。一次研究可以从资产池出发，看到历史资格、策略净值、回撤和成本，再进入有预算、有确认、有审计记录的 AI 研究流程。

本页记录 Wealth Lab 的首次功能分支交付；后续与 main 的融合、股票四维正式评分及复审结果见[主线整合审核](2026-10-26-main-wealth-integration.md)。项目版本仍为 0.10.0，财富 API 保持 v1/v2/v3 的既有通道。

## 新增内容

| 工作区 | 新增能力 |
|---|---|
| 中文前端 | Vue 3 + TypeScript + ECharts；六个主工作区，18 条业务路由，主题切换与像素图标；新增净值、回撤、质量分布、情绪趋势和调用耗时等图表 |
| 多资产研究池 | 登记 33 只研究资产，保留产品形态、市场范围、汇率风险和来源；区分研究资格与历史回测资格，逐调仓重评 PIT |
| 策略工厂 | S0–S8 九策略、四资产基线与扩展池；现金、线性交易成本、初始建仓和换仓均在统一引擎内计算 |
| 受控 AI | 稳定模式最多 2 次调用；实验模式最多 3 次，先明确付费确认，再审批计划。模型角色与实际 model_id 可查询；硬风险检查不能由模型解除 |
| 情绪研究 | 资讯采集、事件去重、资产关联和当前情绪快照；直接证据与类别推导分别标注。社区数据经授权闸门处理，无授权来源默认关闭 |
| 任务与报告 | 白名单任务、真实状态轮询、取消检查点、业务失败/降级展示；研究报告读取指定存档，避免同一 ID 变成另一个实验 |

## 修复过的 Bug

| 触发场景 | 原问题 | 修复后的行为 |
|---|---|---|
| 在全新目录导入后端 | 必需模块只存在于本地未跟踪区 | 补齐入口依赖；干净 Git 副本可以导入 Router |
| 首日建仓 | 按扣费后首日资产归一，初始成本被抹掉 | 净值基于初始本金；首笔成本保留在净值、日收益和审计记录中 |
| S4 逆波动上限 | 截断后再归一，60% 上限被突破 | 逐次固定触顶资产，只在其余资产间分配；约束为调仓目标上限，期间允许价格漂移 |
| ETF 复权因子缺失 | 填 1 或按错误日期方向填充 | 缺失、非正因子明确失败，不猜测补齐 |
| “综合分位”出现负值 | 原始加权秩得分被误称为分位 | 对得分做横截面百分位排名，保持 0—1 语义，不裁剪负值 |
| AI 研究、复核和决策包 | 计算证据为空、研究 ID 未关联回测 | 同一份结构化回测证据向后传递；冲突 ID 拒绝，缺证据明确提示 |
| 年化、总收益与重复数字 | 指标串用、符号错误，一个真值掩盖假值；相同数值的不同位置被合并 | 指标名、单位、方向分别检查；相同数值按原文位置独立核验，并覆盖相同数字重复出现的回归案例 |
| 实验模式付费确认 | 只有按钮勾选，没有确认参数；字符串也能通过 jobs 闸门 | 前端发送真实布尔值；服务端在付费调用前拒绝未确认请求，jobs 拒绝字符串伪装 |
| HTTP 200 + 业务 FAILED | 前端显示执行成功 | FAILED/UNAVAILABLE 显示失败，DEGRADED 显示业务降级，保留错误说明 |
| 公告核验任务 | 未发送必填 claims 与公告选择参数 | 构造并校验 1–20 条声明，要求 record_id 或 announcement_id。只读网关尚未开放的 POST 仍如实失败 |
| generate_report | 用默认参数重算，或读取错误的序列字段 | 兼容既有序列字段，v3 保存全精度净值/回撤，报告保留首日成本并从存档构建；旧存档缺证据时拒绝猜测 |
| PIT 流动性 | 全历史成交均额被误当作近 20 日均额 | 使用截至决策日的最近 20 个有效成交额观测；近期成交枯竭案例被拒绝 |
| 干净环境模型测试 | 断言依赖个人 .env 中的固定模型版本 | 测试对照实际配置，既不猜测模型名，也不为过测试替换真实模型 |
| 交付清理 | 残留调试脚本有语法错误，项目许可证声明不一致 | 删除残留脚本；项目自有 LICENSE、README 与包声明统一为 Apache-2.0，保留第三方许可证 |
| 恢复已有 AI 计划 | 资产池名称调用未定义函数，页面更新中断 | 原样显示后端资产池 ID；已验证存档恢复、模式切换和确认前后按钮状态 |
| 前端构建门禁 | 根 TypeScript 配置只有项目引用，原 `--noEmit` 未检查应用源码 | 构建改用项目构建模式并增加强制类型检查；修正缺失引用、空值保护和类型不一致，严格配置保持启用 |
| 策略对比图 | 条形图已有数据与配置但未连接重绘 | 连接实际比较结果与图表渲染；不更改计算数据 |
| 快照与任务展示 | 同日多条快照标为每日记录；长 JSON 撑高任务行 | 明确标注实际记录时点；任务结果可展开阅读，状态和完整结果均保留 |

COMPLETED 表示流水线结束，不代表收益、研究结论或策略已经获批。数值核验只覆盖程序识别的指标，仍需人工审阅上下文。

## 实跑与验证

发布验证包括：

- 干净候选：**87 个财富后端测试通过**，包含新增的重复数字回归；**30 个前端测试通过**，类型检查和生产构建通过。
- 13 个针对性数字案例符合预期；杠杆场景保持硬 VETO。
- 本地重启 Router 后，确认新版付费字段已加载，主库 Owner 仍为 Router。
- 从真实新版前端运行 S4 四资产历史回测，随后读取其 v2 存档报告。
- 从受控任务队列运行 v3 回测与 generate_report，报告指标与原回测最大差 **4.45e-16**；两个任务均为真实 SUCCEEDED。
- 未确认的实验研究请求返回 **HTTP 422**，未触发模型调用。
- **本轮没有新增真实付费 AI 调用，没有订单、交易或持仓操作。** AI 截图展示角色/确认界面；情绪读取既有快照，没有为截图补造数据。

历史 1,285 项测试是此前的回归基线，本轮没有重新执行全仓测试。前端构建保留 ECharts 包体积警告；这不是构建失败。

## 历史数字如何阅读

本次界面中的 S4 样本：沪深300、国债、黄金、可转债四 ETF，共同区间 **2020-04-07—2026-10-23，1,587 日**；月度调仓，现金零收益，单边 5bps 线性费用，无滑点/冲击成本估计。

| 指标 | 修正后的样本值 |
|---|---:|
| 总收益 | 45.9470% |
| 年化收益 | 6.1873% |
| 年化波动 | 4.5846% |
| 最大回撤 | -5.3351% |
| 项目口径 Sharpe | 0.913344 |

项目 Sharpe 为 `(CAGR−2%)/年化日收益标准差`；使用算术日收益口径时该样本约为 0.896298，两者不要混用。**早期文档中的 S4 Sharpe 1.086 / 回撤 -2.99% 对应上限失效版本，停止用作“60% 上限策略”的展示结果。**

33 只研究资产不是历史全市场成分库，PIT 检查没有消除幸存者偏差。情绪模块只服务当前研究，不进入历史收益计算。截图和回测均不代表未来表现。

## 自己运行一次

先按根 README 配置本地后端与数据，再运行 `frontend/`：

```powershell
cd frontend
npm ci
npm test
npm run build
npm run dev
```

在「策略工厂」选择四资产基线、S4、上述区间与费率即可查看样本。前端地址以 Vite 的实际输出为准，数据和凭据不随代码分发。

后端定向测试：

```powershell
uv run pytest tests/test_wealth_lab_research.py tests/test_wealth_lab_jobs.py tests/test_wealth_lab_v3.py tests/test_wealth_lab_v2.py tests/test_wealth_lab_backtest.py tests/test_wealth_lab_p0_verification.py tests/test_wealth_sentiment_v11.py tests/test_wealth_social_sentiment.py
```

测试可能创建临时数据库；生产数据应按数据库 Owner 约束管理，审查运行使用了独立测试库。
