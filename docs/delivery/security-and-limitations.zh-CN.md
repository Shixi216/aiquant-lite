# 安全与已知限制

- 本产品不支持实盘交易。
- 不包含券商、QMT、xtquant或真实订单能力。
- 不提供一键买入、自动卖出或自动代操。
- 正式策略保持技术面60% + 基本面40%。
- `SHADOW_COMPOSITE` 正式权重为0。
- 硬风险 VETO 不可绕过。
- 正式60/40全市场评价仍为 `INSUFFICIENT_COVERAGE`。
- 当前基本面、情绪、政策和资金覆盖不足。
- 市场快照可能陈旧，界面必须显示数据截止时间和新鲜度。

- 当前结果不能证明稳定盈利或保证收益。
- 企业微信仍仅为适配层，未真实部署。
