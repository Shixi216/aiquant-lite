# 用户手册

- 对话任务：多轮执行扫描、研究和决策支持。
- 技能中心：查看能力、限制、网络和确认要求。
- 市场扫描：只读取本地快照，扫描阶段网络请求和模型调用均为0。
- 正式决策：单只股票且必须二次确认；基本面不足时返回 `INSUFFICIENT_COVERAGE`。
- 自选股：与持仓分离，可保存标签、备注和研究状态。
- 人工成交：只登记用户已完成的外部成交，不向券商发送订单。
- Paper Trading：模拟账户，不代表真实资金和券商成交。
- 回测：仅供研究，`profitability_proven=false`。
- 调度：内置模板默认全部关闭，禁止自动决策、人工成交或真实订单。
