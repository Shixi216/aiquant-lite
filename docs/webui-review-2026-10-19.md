# 中文 WebUI 修复与实拍记录

本次审核使用生产构建的 WebUI、已有本地研究产物和运行中的 Router，未启用开发演示数据。项目自述根据作者提供的经历撰写，没有增加比赛成绩、具体亏损金额或盈利经历。

## 已修复的问题

| 问题 | 修复后 |
|---|---|
| 置信度误用居中评分换算，20% 被显示成约 60 | 按 0—1 概率显示百分比；缺失与越界值保持不可用 |
| 时间展示和轮询窗口受浏览器所在时区影响 | 时间格式化与工作日监测窗口锚定北京时间；无时区时间明确标记未确认 |
| 财务来源事件日被当作报告期 | 报告期读取 `report_period` / `end_date`，与事件日分别展示；冲突和缺失不猜测 |
| 过期快照被描述成“盘后属正常” | 明确提示快照过期，保留真实业务日期 |
| 历史量额相互矛盾仍显示为正常的 0 手及金额 | 对“成交量为零但成交额为正”等记录暂不展示量额，价格记录保留，并提示待核验 |
| 相同折号、不同训练窗口在图表中难以区分 | 横轴同时显示训练窗口和验证折；没有数据的比率不进入图例 |
| 未选中的研究页提前挂载、请求和初始化图表 | 研究面板按选中的标签页挂载 |
| 一个健康接口失败导致其余健康信息一并消失 | 各接口独立呈现，失败部分明确提示 |
| 搜索失焦使用模板中的定时器、清空后可能被旧响应覆盖，键盘候选无法选择 | 使用脚本内失焦处理，失效旧请求，支持 Enter 选择候选 |
| 错误、组件名、财务类型和候选策略混用英文代码 | 默认界面使用中文解释；诊断原文单独折叠保留 |

轮询按上海时区的工作日监测窗口调度，不等于完整交易所节假日日历。页面卸载后，在途请求完成也不会重新启动轮询。

## 验证结果

| 检查 | 结果 |
|---|---|
| 前端回归 | **14 passed，0 failed，0 skipped** |
| WebUI 后端范围：V2、量化、K 线链路三个模块 | **58 passed，0 failed，0 skipped**；隔离临时数据库 |
| TypeScript 与 Vite 生产构建 | 通过 |
| 浏览器实际检查 | 市场总览、机会排序、个股、量化、策略研究和系统健康；检查过程中未记录到前端错误 / 警告 |
| 中文搜索 | 输入“茅台”，用 Enter 选择候选后进入正确个股页，候选列表关闭 |
| 响应式检查 | 桌面与 390px 手机断点；市场 / 机会页面无页面级横向溢出，手机导航可展开并在切换后收起 |

Vite 仍提示图表依赖分块超过 500KB。这里是本次相关模块的验证，不替代全仓库测试、外部数据质量或策略有效性检验。
