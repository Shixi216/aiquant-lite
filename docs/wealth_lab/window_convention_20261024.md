## 二、差异归因（实证）

2020-04-07→04-08 单日收益：沪深300 **-0.397%**、国债 **+0.422%**、黄金 **-0.952%**、转债 **-0.010%**。

1. **调仓序列零分叉**：两口径 78 个共同调仓日的目标权重完全一致（逐日比对 0 处不同）；
   1587 口径只多一个首日建仓事件（04-07）。不存在"临界历史天数导致策略选不同资产"的分叉。
2. **S3（56.20% vs 55.54%，差 0.66pp）**：S3 首月历史不足持防御国债。1587 口径在 04-07 收盘建仓国债，
   吃到 04-08 国债 +0.422%；比率验证 1.561974/1.555406 = 1.00422 ≈ 1+0.422%，逐位吻合。
3. **S4（45.95% vs 46.30%，差 -0.35pp）**：S4 首月历史不足等权建仓。04-08 等权单日
   (-0.397+0.422-0.952-0.010)/4 = **-0.234%**；比率 1.459470/1.462952 = 0.99762，吻合。
   1587 口径因多含这一天下跌日而总收益略低——不是"更差"，是**更长更真实的区间**。
4. **S2（两口径总收益完全相同）**：S2 历史不足持币，首日现金零收益零成本——
   构成完美对照，证明差异仅由首日资产暴露差异驱动，引擎本身确定性一致。
5. 年化/Sharpe 的小差异（如 S2 5.6324% vs 5.6360%）为天数分母（252/年换算）效应，同源。
