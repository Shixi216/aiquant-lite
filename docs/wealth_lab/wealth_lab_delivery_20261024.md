## 三、数据质量说明

1. **净值口径**：fund_daily 收盘价 × fund_adj 累计复权因子（后复权），
   已包含分红再投资效应；四资产复权因子完整（adj_missing=0）。
2. **共同交易日**：511380 上市（2020-03）之前三资产数据存在但回测
   仅使用四资产共同区间；压力测试窗口允许资产子集（响应标注
   `window_missing_assets`）。
3. **成本模型**：Σ|Δ权重| × cost_bps/1e4，等价双边各按单边费率收取；
   未建模申赎佣金阶梯、冲击成本与跟踪误差。
4. **已知限制**：ETF 场内价格口径（IOPV 折溢价未处理）；停牌日沿用
   前收盘（复权因子 ffill）；回测为研究用途（research_only=true），
   不构成投资建议。
5. **数据源审计**：当前池全部 OFFICIAL；代理源仅在官方积分/限频/网络
   失败时自动降级，且每行记录实际来源。

## 四、接口速查（详见契约）

```
GET  /v1/wealth-lab/meta                    # 版本/数据池状态
GET  /v1/wealth-lab/assets                  # 资产列表+覆盖+来源
POST /v1/wealth-lab/backtests/run           # 回测（默认参数可空body）
GET  /v1/wealth-lab/backtests/{id}          # 取回已存回测
GET  /v1/wealth-lab/backtests/{id}/risk     # 滚动风险/VaR/最差日
POST /v1/wealth-lab/stress-tests            # 历史/合成压力测试
```

响应统一信封（request_id/status/data/...research_only），数据模式
`data_mode: REAL | DEMO | UNAVAILABLE`；DEMO 序列固定 seed 合成并在
`series.demo=true` 与 caveats 中强制标注，防演示数据混入真实结果。
